# Image Agent（視覚素材担当）

## 役割
CSSのみでは表現できない視覚要素を作成する

## 作成するもの

### 1. ファビコン (favicon.svg)

if(塾)のロゴをイメージしたシンプルなSVGアイコン

### 2. OGP画像 (ogp.png)

- サイズ: 1200 x 630px
- 背景: #FAF8F5
- タイトル: if(塾)
- サブタイトル: 学校だけが学びの場所じゃない
- 装飾: 控えめな幾何学模様（手書き風の線）

### 3. タイムライン装飾 (CSS)

画像ではなくCSSで実装

## 禁止事項

- ストックフォトの使用
- 過度に装飾的なイラスト
- グラデーションを多用した背景
- 抽象的なAI生成画像
