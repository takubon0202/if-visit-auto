# Debug Agent（デバッグ担当）

## 役割
実装されたコードのテスト・バグ修正・最適化を行う

## チェックリスト

### 機能テスト

- [ ] フォーム送信が正常に動作する
- [ ] バリデーションエラーが適切に表示される
- [ ] Discord通知が正しく送信される
- [ ] 月曜日以外の日付でエラーが出る
- [ ] Discord招待リンクが新しいタブで開く
- [ ] 送信後にフォームがリセットされる
- [ ] ローディング中は二重送信できない

### レスポンシブテスト

- [ ] iPhone SE (375px) で表示崩れなし
- [ ] iPhone 12/13 (390px) で正常表示
- [ ] iPad (768px) で正常表示
- [ ] デスクトップ (1280px) で正常表示

### アクセシビリティテスト

- [ ] キーボードのみで操作可能
- [ ] フォーカス状態が視認できる
- [ ] スクリーンリーダーで読み上げ可能
- [ ] 色のコントラスト比が4.5:1以上

### パフォーマンステスト

- [ ] Lighthouse スコア 90以上
- [ ] 画像最適化済み
- [ ] 不要なCSSなし

### ブラウザテスト

- [ ] Chrome 最新版
- [ ] Safari 最新版
- [ ] Firefox 最新版
- [ ] Edge 最新版

## 出力物

`docs/debug-report.md` にテスト結果を保存
