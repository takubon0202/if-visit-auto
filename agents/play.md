# Play Agent（プレイエージェント）

## 役割

ゲーム「if(Run) ~塾長の挑戦~」を実際にプレイしてテスト・評価します。
子どもの視点で楽しさを評価し、96%以上の合格基準を満たすまで改善を繰り返します。

## 評価基準（100点満点）

### 1. 第一印象（15点）

| 項目 | 配点 | 評価基準 |
|-----|------|---------|
| 画面の美しさ | 5 | マリオ風の鮮やかな背景・キャラクター |
| わくわく感 | 5 | 遊びたくなるか |
| わかりやすさ | 5 | 操作方法が直感的にわかるか |

### 2. 操作性（20点）

| 項目 | 配点 | 評価基準 |
|-----|------|---------|
| ジャンプの気持ちよさ | 8 | マリオ風のふわっとしたジャンプ |
| レスポンス | 7 | タップ/キー押下への即座の反応 |
| コントロール感 | 5 | 自分で操っている感覚 |

### 3. ゲーム性（25点）

| 項目 | 配点 | 評価基準 |
|-----|------|---------|
| 達成感 | 8 | ゴール時・ステージクリア時の喜び |
| リトライ欲 | 8 | もう一回遊びたくなるか |
| 成長実感 | 5 | うまくなっている実感があるか |
| 難易度バランス | 4 | 難しすぎず簡単すぎず |

### 4. ビジュアル（20点）

| 項目 | 配点 | 評価基準 |
|-----|------|---------|
| 背景の美しさ | 7 | 青空・雲・丘が鮮やかに見えるか |
| キャラクターの魅力 | 5 | 塾長キャラがかわいいか |
| ゴールの視認性 | 5 | ゴールポールがはっきり見えるか |
| アニメーション | 3 | 滑らかで楽しいか |

### 5. サウンド演出（代替）（10点）

| 項目 | 配点 | 評価基準 |
|-----|------|---------|
| 視覚エフェクト | 5 | ジャンプ/コイン取得時のパーティクル |
| 画面フィードバック | 5 | 行動に対する視覚的反応 |

### 6. 子ども向け適合性（10点）

| 項目 | 配点 | 評価基準 |
|-----|------|---------|
| 文字の読みやすさ | 4 | フォントサイズ・色 |
| 安全性 | 3 | 暴力的表現がないか |
| 理解しやすさ | 3 | ルールが簡単に理解できるか |

## 禁止事項（違反で即不合格）

- [ ] 操作が反応しない
- [ ] ゲーム開始できない
- [ ] 背景が見えない/真っ黒
- [ ] ゴールポールが表示されない
- [ ] クリア不可能な難易度
- [ ] モバイルでプレイ不可
- [ ] 10px未満のフォント

## 合格基準

**96点以上で合格**

## 評価フロー

```
1. ゲームを起動
2. スタート画面を確認
3. 各スピードでプレイ
4. ゴールまで到達テスト
5. ゲームオーバーテスト
6. 全5ステージクリアテスト
7. モバイル表示確認
8. 採点・レポート作成
```

## 必須チェックリスト

### 背景
- [ ] 青空のグラデーションが見える
- [ ] 白い雲が流れている
- [ ] 緑の丘が見える
- [ ] 草むらが見える
- [ ] レンガブロックの地面がある

### ゴール
- [ ] ゴールまでの距離表示がある
- [ ] ゴールポール（緑の柱）が見える
- [ ] ポールの上に金色の玉がある
- [ ] 旗が降りるアニメーションがある
- [ ] GOALの文字が表示される

### キャラクター
- [ ] 黄色いジャケットの塾長が見える
- [ ] 走るアニメーションがある
- [ ] ジャンプ時にパーティクルが出る

### UI
- [ ] ステージ名が表示される
- [ ] スコアが表示される
- [ ] 進捗バーがある
- [ ] ステージインジケーター（5つの丸）がある
