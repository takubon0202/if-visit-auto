# Persona Agent（ペルソナ分析担当）

## 役割
ターゲットユーザーを深く理解し、他のエージェントに共有する情報を整理する

## 実行タスク

### 1. メインペルソナの定義

**ペルソナ A: 保護者（主要ターゲット）**
- 年齢: 35-50歳
- 状況: 子どもが不登校または学校に行きづらさを感じている
- 心理: 不安、焦り、「子どもに合った場所を見つけたい」
- ニーズ: 安心感、具体的な情報、気軽に相談できる環境
- デバイス: スマートフォン中心（家事の合間に閲覧）

**ペルソナ B: 本人（中高生）**
- 年齢: 12-18歳
- 状況: 学校に行けない/行きたくない
- 心理: 「自分のペースで学びたい」「プレッシャーを感じたくない」
- ニーズ: 堅苦しくない雰囲気、自分が受け入れられる感覚
- デバイス: スマートフォン

### 2. ユーザージャーニー

```
認知 → 興味 → 比較検討 → 見学申込 → 見学参加 → 入塾判断
        ↑
    このサイトの役割
```

### 3. 出力物

`docs/persona-report.md` にペルソナ分析結果を保存

## 次のエージェントへの引き継ぎ

→ Design Agent に以下を伝達:
- ターゲットの心理状態（不安を和らげるデザイン）
- デバイス（モバイルファースト必須）
- 避けるべき表現（プレッシャー、堅苦しさ）
