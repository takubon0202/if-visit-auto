# ペルソナ分析レポート

## 1. メインペルソナ

### ペルソナ A: 保護者（主要ターゲット）

| 項目 | 詳細 |
|-----|------|
| 年齢 | 35-50歳 |
| 状況 | 子どもが不登校または学校に行きづらさを感じている |
| 心理状態 | 不安、焦り、「子どもに合った場所を見つけたい」 |
| 主なニーズ | 安心感、具体的な情報、気軽に相談できる環境 |
| デバイス | スマートフォン中心（家事の合間に閲覧） |

**心理的特徴**:
- 「普通の塾とは違う選択肢がほしい」
- 「子どもを理解してくれる大人に出会いたい」
- 「プレッシャーを与えたくない」
- 「でも将来のために何かしてあげたい」

**情報収集パターン**:
- 検索キーワード: 「不登校 居場所」「フリースクール 秋田」「オンライン塾 子どものペース」
- SNS（特にX/Twitter、Instagram）での情報収集
- 口コミや体験談を重視

### ペルソナ B: 本人（中高生）

| 項目 | 詳細 |
|-----|------|
| 年齢 | 12-18歳 |
| 状況 | 学校に行けない/行きたくない |
| 心理状態 | 「自分のペースで学びたい」「プレッシャーを感じたくない」 |
| 主なニーズ | 堅苦しくない雰囲気、自分が受け入れられる感覚 |
| デバイス | スマートフォン |

**心理的特徴**:
- 「また失敗したらどうしよう」という不安
- 「自分らしくいられる場所がほしい」
- ゲームやプログラミングへの興味
- 大人からの過度な期待へのストレス

**避けるべき表現**:
- 「頑張ろう」「努力」などの圧力を感じる言葉
- 成績や結果を強調する表現
- 堅苦しいフォーマルな文体

```

└─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
                    ↑              ↑              ↑
                    └──────────────┴──────────────┘
                         このサイトの役割
```

### 各段階での心理と必要な情報

| 段階 | 心理 | 必要な情報 |
|-----|------|-----------|
| 認知 | 「こんな塾があるんだ」 | 塾の基本コンセプト |
| 興味 | 「うちの子に合うかも」 | 特徴、雰囲気、対象 |
| 比較検討 | 「他と何が違う？」 | 具体的な内容、料金、講師 |
| 見学申込 | 「まず見てみよう」 | 見学の流れ、日程、申込方法 |

## 3. if(塾)の強み（公式サイト分析より）

### ターゲットに響くポイント

1. **決まったカリキュラムがない**
   - 自分のペースで進められる安心感
   - プレッシャーを感じにくい

2. **オンライン対応**
   - 家から出なくていい（心理的ハードルが低い）
   - 全国どこからでも参加可能

3. **AI先生による24時間サポート**
   - いつでも質問できる安心感
   - 人に聞くのが苦手でも大丈夫

4. **不登校児童への理解**
   - 「第三の居場所」としての位置づけ
   - 学校復帰実績がある

5. **若い講師陣**
   - 高校生起業家が講師
   - 年齢が近く親しみやすい

## 4. Design Agentへの引き継ぎ事項

### デザインで重視すべき点

1. **安心感を与える色使い**
   - 温かみのあるアースカラー
   - 刺激の少ない落ち着いた配色

2. **モバイルファースト必須**
   - 保護者はスマホで閲覧
   - フォームは親指で操作しやすく

3. **避けるべき表現**
   - 「頑張る」「努力」などの圧力語
   - 成績・結果を強調する表現
   - 堅苦しいビジネス調の文体

4. **伝えるべきメッセージ**
   - 「自分のペースでいい」
   - 「まずは気軽に見学から」
   - 「ここには理解してくれる人がいる」

### キャッチコピー案

- メイン: 「学校だけが学びの場所じゃない」
- サブ: 「自分のペースで、自分らしく」
