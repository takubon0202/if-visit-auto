# if(塾) 見学申し込みサイト

塾見学希望者向けの申し込みサイトです。サイバーパンク/メタバース風のデザインで、予約管理機能を備えています。

## 機能一覧

- 新規見学申し込み
- 予約変更（予約IDとメールアドレスで認証）
- 予約キャンセル
- **月曜日専用カレンダー**（16:45-18:15の時間帯のみ選択可能）
- **予約情報のローカル保存**（申し込み済みユーザーのみ変更・キャンセルタブ表示）
- Googleスプレッドシートへのデータ蓄積
- Discord通知（新規・変更・キャンセル）
- 週間予約サマリー通知
- **if(Run) ~塾長の挑戦~**（子ども向けマリオ風ランナーゲーム）

## 予約変更・キャンセル機能

予約変更・キャンセルタブ（およびパネル全体）は**申し込み済みユーザーのみ**に表示されます。

### 仕組み
1. **初回訪問時**: 「新規申し込み」タブのみ表示（変更・キャンセルは非表示）
2. **申し込み完了後**: 予約IDとメールアドレスがブラウザに保存される
3. **タブ・パネル表示**: 保存された予約情報がある場合、「予約変更」「キャンセル」タブとパネル全体が表示される
4. **自動入力**: フォームに予約情報が自動入力される
5. **クリア**: 予約情報をクリアすると、タブ・パネルが非表示になる

### Discord通知
- **新規申し込み**: シアン色のEmbed
- **予約変更**: 黄色のEmbed（変更前後の日程を表示）
- **キャンセル**: 赤色のEmbed

## カレンダー機能

見学は**毎週月曜日 16:45-18:15**のみ受付可能です。

- 月曜日のみクリック可能なビジュアルカレンダー
- 過去の日付は選択不可
- 選択すると日付と時間が表示される
- 最大3ヶ月先まで予約可能

## if(Run) ~塾長の挑戦~

子ども向けの**マリオ風ランナーゲーム**を搭載。マリオブラザーズ風の背景で、塾長キャラクターが冒険します。

### ゲーム仕様

- **操作方法**
  - PC: スペースキー / ↑キーでジャンプ
  - モバイル: 画面タップでジャンプ
- **ゲーム要素**
  - 障害物: 土管、クリボー風敵、穴
  - アイテム: コイン（+100点）、スター（無敵+500点）
  - ゴール: 3000m到達でクリア
- **ビジュアル**
  - マリオブラザーズ風の青空背景
  - 雲、丘、草むらのスクロール
  - レンガブロック風の地面
- **表示オプション**
  - 埋め込みプレイ
  - フルスクリーン（別タブ）対応

### キャラクター

黄色いジャケットを着た男の子がif(塾)のマスコットキャラクター（塾長）です。

## セットアップ

### 方法1: Google Apps Script を使用（推奨）

スプレッドシートにデータを蓄積し、Discord通知も行えます。

#### Step 1: Google スプレッドシートの作成

1. [Google スプレッドシート](https://sheets.google.com/)で新しいスプレッドシートを作成
2. 「拡張機能」→「Apps Script」を選択

#### Step 2: GASコードの設置

1. `gas/Code.gs` の内容をすべてコピー
2. Apps Script エディタに貼り付け
3. `CONFIG.DISCORD_WEBHOOK_URL` を自分のWebhook URLに変更:
   ```javascript
   const CONFIG = {
     DISCORD_WEBHOOK_URL: 'https://discord.com/api/webhooks/...',
     // ...
   };
   ```

#### Step 3: デプロイ

1. 「デプロイ」→「新しいデプロイ」をクリック
2. 種類で「ウェブアプリ」を選択
3. 設定:
   - 説明: if(塾) 見学申し込み
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: **全員**
4. 「デプロイ」をクリック
5. 表示されたウェブアプリURLをコピー

#### Step 4: フロントエンド設定

`js/config.js` を編集:

```javascript
const CONFIG = {
  GAS_WEB_APP_URL: 'https://script.google.com/macros/s/xxxxx/exec',
  DISCORD_INVITE_URL: 'https://discord.gg/your-invite',
  // ...
  MODE: {
    useGAS: true,  // GASを使用
  }
};
```

### 方法2: Discord Webhook のみ使用

スプレッドシートへの蓄積なしで、Discordに直接通知します。

`js/config.js` を編集:

```javascript
const CONFIG = {
  DISCORD_WEBHOOK_URL: 'YOUR_DISCORD_WEBHOOK_URL',
  DISCORD_INVITE_URL: 'YOUR_DISCORD_INVITE_LINK',
  // ...
  MODE: {
    useGAS: false,  // Webhookを直接使用
  }
};
```

## 内部フロー

### 新規予約フロー
```
1. ユーザーがサイトにアクセス
2. 「新規申し込み」タブでフォームを入力
3. カレンダーから月曜日を選択（他の曜日は選択不可）
4. 「送信」ボタンをクリック
5. フロントエンドでバリデーション
6. GAS Web App にPOSTリクエスト
7. スプレッドシートに保存 + 予約ID発行
8. Discord通知（シアン色のEmbed）
9. ユーザーに予約IDを表示
```

### 予約変更フロー
```
1. 「予約変更」タブを選択
2. 予約ID・メールアドレスを入力
3. 新しい希望日をカレンダーから選択
4. GAS経由で認証 + 更新
5. Discord通知（黄色のEmbed）
```

### キャンセルフロー
```
1. 「キャンセル」タブを選択
2. 予約ID・メールアドレスを入力
3. 確認ダイアログで同意
4. GAS経由で認証 + ステータス更新
5. Discord通知（赤色のEmbed）
```

## エージェントシステム

品質を保証するため、以下のエージェントが協働評価します：

| エージェント | 役割 | 評価ウェイト |
|------------|------|------------|
| Design Agent | UI/UX・文字視認性 | 35% |
| Visitor Agent | 見学予定者視点 | 35% |
| Coding Agent | コード品質 | 30% |
| Game Agent | if(Run)ゲーム開発 | - |
| Responsive Agent | レスポンシブ対応 | - |
| Evaluator Agent | 統合評価・合否判定 | - |

**合格基準: 90点以上**（3倍厳格化）

## 予約IDについて

予約完了時に発行される予約IDは以下の形式です:
```
IF-YYYYMMDDHHMMSS-XXXX
例: IF-20241230143025-1234
```

このIDは予約変更・キャンセル時に必要です。

## セキュリティ考慮事項

### Webhook URLの保護

広く公開する場合は以下の対策を検討してください：
1. **GAS経由（推奨）**: Webhook URLがバックエンドに隠蔽されます
2. **Cloudflare Workers** を経由してWebhookを呼び出す
3. **Netlify/Vercel Serverless Functions** を使用

### スパム対策

- reCAPTCHA v3 の導入を検討
- GASでレート制限を実装
